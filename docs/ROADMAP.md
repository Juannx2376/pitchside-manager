# Roadmap

Honest list of known gaps and ideas, roughly by impact. Pull requests welcome.

## High impact
- **In-match assistant**: proactive tips ("your full-back is tired") and deeper post-match analysis.
- **Dressing room**: social groups, leaders and captain influence on morale.
- **Contracts overview**: bulk renewals, an expiry timeline and a "lose for free" watch-list.
- **Stadium and fans**: atmosphere, season-ticket dynamics and rivalries with real effects.
- **Onboarding**: a guided mode for the first weeks, not only the tooltip tour.

## Transfers
- AI-initiated player-plus-cash proposals beyond simple swaps.
- Loan-out negotiations with the buy option shaped by the user.
- Agent relationships and player-agent fees as a long-term resource.

## Development
- Youth team fixtures (U18/U21) and academy staff roles with their own decisions.
- Individual training "specialisations" and injury rehab programmes.

## Platform
- Cloud / file backup of saves and an import/export UI for the browser.
- Local notifications and a native shell (a Capacitor Android project is already in `apps/web/android`).
- Performance profile of the full 211-country world on low-end devices.

## Quality
- Broaden calibration tests of the match engine across leagues.
- More E2E coverage for press, career and unemployment flows.
